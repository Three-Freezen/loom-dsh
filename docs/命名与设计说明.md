## 一、命名：Loom（定稿）

**Loom** 意为「织机」。DSH 的 profile 本身就是一层层 patch / bundle「织」成的；
更新相当于换一台织机，而 Loom 的职责是**把插件重新织回新运行时**。
与 DSH（Harness，织具意象）同族，词短、好念，命令行可直接用 `loom`。
产品全称建议：**Loom for DSH**；文案风格保持**工具理性**（快照 / 恢复 / 兼容），不做拟人化。

其余候选作为备选记录（如后续想要更"航运/园艺"气质可换）：

## 二、图标（Loom）

### 寓意
- **浅底/深底圆角方**：沿用 DSH 应用图标语言（DSH 是白底深色鲸鱼），像同族工具；
  深底版用于深色任务栏/深色背景，浅底版用于桌面与浅色场景。
- **三条圆角横条**：DSH profile 里层层叠加的 bundle / patch（插件层）。
- **蓝色 S 线**：织机经线，一上一下穿过三层 = **把插件重新织进新版本**。
- **底部结块 + 两种收尾**：
  - **对钩**：兼容校验通过 / 恢复完成；
  - **圆点**：打结固定（快照落盘 / 已就绪）。
- **颜色**：DSH 主蓝 **#4176e6**（deepseek-500）；深色 `#191a1d`，与 DSH 主文字同族。
- **小尺寸**（≤48px）自动切换简化标记（两层 + 一次穿线 + 对钩/圆点），保证 16px 托盘可读。

### 收尾版本（已定稿：对钩）
- 底部结块收尾采用 **对钩**（兼容校验通过 / 恢复完成）。
- **圆点结**版本未采用，已存档到 `alternatives/` 目录，需要时可直接取用。

### 文件（1024 矢量 + PNG + 多尺寸 ICO）
| 变量 | SVG | PNG | ICO |
|---|---|---|---|
| 浅底 · 对钩（主图标） | `LOOM-icon-light-check.svg` | `LOOM-icon-light-check.png` | `LOOM-icon-light-check.ico` |
| 深底 · 对钩（深色场景/托盘） | `LOOM-icon-dark-check.svg` | `LOOM-icon-dark-check.png` | `LOOM-icon-dark-check.ico` |

ICO 含 16/24/32/48/64/128/256 多尺寸，可直接用于托盘/窗口/exe 图标。
定稿总览图：`LOOM-icons.svg` / `LOOM-icons.png`；圆点结备选：`alternatives/`。

|---|---|---|---|

| 强调 | `#7aaaff`（deepseek-400） | `#4176e6`（deepseek-500） | 链接、状态、图标蓝线 |
| 成功 / 警告 / 危险 | `#4ed17e` / `#f59e0b` / `#f25a5a` | `#22c55e` / `#f59e0b` / `#ef4444` | 状态 |
| Toast | `#43454a` + 白字 | 同左（深色气泡在浅色下同样成立） | 通知 |
| 字体 | Montserrat 300/500（品牌）+ Segoe UI / 微软雅黑 400/500（界面） | 同左 | — |
| 主按钮 | 白底深字 44px / 12px 圆角（原生弹窗规格） | 黑底白字 | 主动作 |
| 窗口 / 弹层 / 卡片圆角 | 18 / 20 / 14 px | 同左 | — |

### 界面组成（每套参考图均含）
1. **托盘弹层**：状态卡（DSH 版本 / 已保护插件 / 快照时间 / 占用/检查频率）→ 主按钮「立即快照」→ 次级动作「检查兼容性 / 打开备份目录」→ 最近活动 → 底部报告与退出。
2. **设置窗口**：左导航（通用 / 备份与还原 / 更新与兼容 / 通知 / 存储 / 关于）+ 右侧卡片：兼容策略（默认**自动升级到兼容版本**）、更新后自动恢复、快照与存储。
3. **Windows Toast**：已备份 / 发现新版本两类通知。
4. **兼容性提示卡**：自动升级清单；仅"查不到兼容版本"时出现人工确认（稍后 / 立即处理）。
5. **设计 Token 区**：颜色、字体、圆角、字号一览，可直接映射到 WPF / WebView2 实现。

## 四、已确认决策

| 项 | 结论 |
|---|---|
| 名称 | **Loom**（织机）；命令行 **`loom-dsh`**；产品名 Loom for DSH |
| 图标蓝色 | DSH 主蓝 `#4176e6` |
| 底部收尾 | **对钩**（定稿；圆点结备选存档于 `..\design\icons\alternatives\`） |
| 主题 | 深色 + 浅色两套都出 |
| 文案风格 | 保持工具理性（快照 / 恢复 / 兼容） |
| 更新方式 | 应用内自动更新 |
| 兼容冲突 | 策略 A：自动查询并升级到兼容版本 |
| 更新后重启 | 可接受最多重复启一次 |
| 交付形态 | 绿色免安装 Windows 托盘工具 + 同名 CLI（非 DSH 插件） |
| 实现技术 | **.NET 10 WPF（自包含单文件 win-x64）+ WinForms NotifyIcon**；CLI 与托盘同一 `loom-dsh.exe` |
| 首版范围 | **A**：快照 + check + 文件级还原 + 报告 + 托盘 + 设置（策略 A 进二期） |
