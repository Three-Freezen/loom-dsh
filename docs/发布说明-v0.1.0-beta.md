# Loom for DSH v0.1.0-beta

> 首个公开测试版本（Windows 10/11 x64）。本页内容同时用作 GitHub Release **v0.1.0-beta** 的正文。

Loom（织机）是一个 Windows 托盘小工具 + 同名 CLI：在 DeepSeek Harness 桌面版每次自动更新后，保护并恢复已安装的插件（`desktop` profile 的 bundles、配置与兼容性状态），并在存在版本兼容风险时提示与处置。它**不是** DSH 插件，不修改 DSH 安装目录，也不替代 DSH 自身的插件管理。

---

## 本版亮点

### 1. 托盘右键菜单（WPF 自绘）
- 深/浅主题跟随应用主题；10px 圆角卡片、36px 行高、16px 图标列、贯穿式分割线、淡入效果。
- 修复「右键 → 打开状态面板」点击无反应的根因：先同步关闭菜单、在菜单关闭完成后再执行动作；弹层增加 300ms/未激活失焦保护；前台激活失败时用鼠标捕获兜底关闭。
- 深/浅主题各有渲染预览（`design/ui/impl-preview/`）。

### 2. 图标一致性
- 软件内 LogoMark 按设计 SVG 精确重绘，深/浅主题两套；窗口图标随主题切换。
- 托盘 ICO 底色跟随应用生效主题（深底/浅底两套，16–256 共 7 个尺寸帧）；对钩统一为品牌蓝 `#4176e6`。

### 3. Inno Setup 安装包
- 免管理员安装到当前用户目录（默认 `%LOCALAPPDATA%\Programs\Loom`，向导可改），不写 Program Files、不写 HKLM。
- 固定安装包文件名 `loom-dsh-Setup.exe`（应用内更新的固定资产名依赖）。
- 固定 AppId 覆盖升级；`AppMutex` 单实例保护；静默升级 `/SILENT /DIR="<安装目录>"`；升级/卸载都不会删除用户数据目录 `Data`。

### 4. 安装目录数据根 + 旧数据自动迁移
- 数据根解析优先级：`--data-root <目录>` > 便携标记 `<exe目录>\Data\portable.flag` > `<安装目录>\Data`（Inno 安装版）> `%LOCALAPPDATA%\Loom`（绿色版/开发版）。
- 安装版**首次启动**自动把旧 `%LOCALAPPDATA%\Loom` 的设置/快照/报告/日志复制到 `<安装目录>\Data`：幂等、不覆盖已有文件、跳过 `queue\`/锁/临时文件、自动重写 `state.json`/`config.json` 内的旧绝对路径、写 `Data\migration.json`，**只复制不删除**旧目录。
- 手动入口：`loom-dsh migrate-data`（支持 `--dry-run` / `--remove-source` / `--json`）。

### 5. 应用内更新（GitHub Releases）
- **检查**：读取 GitHub Releases `latest`（网页端点 302 取 tag，避开 REST API 匿名限流；REST API 作为网关拦截重定向时的兜底），与当前版本比较。
- **下载**：从 `releases/latest/download/loom-dsh-Setup.exe`（固定资产名）下载到用户「下载」目录（不可写时用 `<数据根>\updates`）；先写 `.part` 再原子改名，并过滤过小文件/HTML 错误页。
- **安装**：先退出托盘、释放单实例锁，再以 `/SILENT /DIR="<当前安装目录>"` 静默升级；安装器 `[Run]` 项装完自动重启应用；可选升级后自动清理下载的安装包。
- 安装版默认每 24 小时自动检查一次（失败同样节流，可在设置中开关）；设置页提供「检查更新 / 下载 / 重启并更新」。
- CLI：`loom-dsh update [--download] [--apply] [--json]`。
- 仅 Inno 安装版支持应用内更新；绿色版/开发版会提示到发布页手动下载。

## 安装方式

### 方式一：安装包（推荐）

1. 下载 `loom-dsh-Setup.exe`。
2. 双击安装：免管理员；向导可改安装目录（默认 `%LOCALAPPDATA%\Programs\Loom`）；可选创建桌面快捷方式；结束页可勾选立即运行。
3. 启动后托盘出现 Loom 图标，右键可打开菜单与状态面板。

```powershell
# 交互安装
loom-dsh-Setup.exe

# 静默升级到原安装目录（应用内更新/脚本使用同样参数；装完自动重启）
loom-dsh-Setup.exe /SILENT /DIR="<当前安装目录>"

# 静默卸载（用户数据目录 Data 不会被删除）
<安装目录>\unins000.exe /VERYSILENT /NORESTART
```

### 方式二：绿色版（免安装）

```powershell
# 直接启动托盘；数据根为 %LOCALAPPDATA%\Loom
loom-dsh.exe

# 便携模式：在 exe 旁创建 Data\portable.flag（内容任意），数据改放 <exe目录>\Data
```

### CLI（与托盘是同一个 exe）

```powershell
loom-dsh.exe status                  # 状态
loom-dsh.exe snapshot                # 立即快照
loom-dsh.exe check                   # 兼容性检查（存在未验证/不兼容时退出码 2）
loom-dsh.exe restore --dry-run       # 文件级还原演练
loom-dsh.exe doctor                  # 环境体检
loom-dsh.exe migrate-data            # 旧数据目录迁移到当前数据根
loom-dsh.exe update                  # 检查更新（--download 下载，--apply 静默升级并重启）
loom-dsh.exe --help                  # 完整帮助
```

## 系统要求

- **Windows 10 x64 或更高版本**（安装包 `ArchitecturesAllowed=x64compatible`）。
- 主程序为 .NET 10 WPF、自包含 win-x64 单文件，**无需预装 .NET 运行时**。
- **免管理员**：安装到当前用户目录；不需要写 HKLM / Program Files。
- **未签名**：exe 与安装包均未做代码签名，首次运行/安装时 SmartScreen 可能提示，请核对上方 SHA256 后再运行。

## 已知限制

1. **未签名**：安装包与 exe 都没有代码签名，SmartScreen 可能拦截；代码签名在后续版本。
2. **发布前真机 smoke（4 项，沙箱环境标记 ENV-LIMITED）**：受限沙箱无法完成，需在真实 Windows 桌面各确认一次——
   - ① 正式安装包安装/升级/卸载（卸载注册项、开始菜单、桌面快捷方式、中文向导、图标）；
   - ② 通知区右键 → 菜单 →「打开状态面板」→ 弹层可交互，点外部/Esc 可关闭；
   - ③ 静默升级 `[Run]` 在装完后自动重启应用；
   - ④ 数据目录 ACL 实际生效（`icacls <安装目录>\Data`）。
3. **应用内更新需真机联网 smoke**：检查 → 下载 → 静默升级 → 自动重启全链路需要在一台真实安装版上走一遍（沙箱只验证了本地源与参数链路）。
4. **自动迁移只复制不删除**：旧 `%LOCALAPPDATA%\Loom` 会保留，确认新目录数据完整后可手动执行 `loom-dsh migrate-data --remove-source` 清理。
5. **迁移的路径重写范围有限**：只重写 `state.json`/`config.json` 中记录的快照、报告等 5 类绝对路径；历史 `reports\*.json`、`snapshots\*\snapshot.json` 内部仍可能显示旧路径，不影响 Check/Restore。
6. **托盘菜单/弹层**：真实通知区下的右键、前台激活、高 DPI/混合 DPI 双屏表现为真机 smoke 项；菜单未激活时 Esc/方向键不可用属 Windows 限制（已用鼠标捕获保证点击外部可关闭）。
7. **数据目录 ACL**：代码会尝试收紧为「当前用户 + SYSTEM」；在受限令牌环境下可能回退为继承权限，请勿分享数据目录。
8. **本版范围**：快照 / 兼容性检查 / 文件级还原 / 报告 / 托盘与设置 / 安装包 / 数据迁移 / 应用内更新。策略 A 全自动升级、包级恢复、离线完整回滚、代码签名在后续版本。

## 数据安全说明

- Loom **只操作自己的数据根**（`<安装目录>\Data`、`%LOCALAPPDATA%\Loom`、便携目录或 `--data-root` 指定目录）；**不修改** DSH 安装目录与 `app.asar`；**不自动结束** DSH 进程；**不自动授予**兼容性风险豁免。
- **升级/卸载不删除数据**：`Data\` 不在安装器 `[Files]` 清单内（仅以 `uninsneveruninstall` 创建目录），升级只替换主程序，卸载只删除自己写入的文件。
- **迁移只复制、不删除**：自动迁移幂等、不覆盖已有文件、跳过 `queue\`/锁/临时文件；清理旧目录必须由用户显式执行 `migrate-data --remove-source`。
- 建议定期备份 `<安装目录>\Data`（或 `%LOCALAPPDATA%\Loom`），其中包含设置、快照与报告。
